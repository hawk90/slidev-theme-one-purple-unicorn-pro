# create-one-purple-unicorn

A new [Slidev](https://sli.dev) deck with the [One Purple Unicorn Pro](https://github.com/hawk90/slidev-theme-one-purple-unicorn-pro) theme:

```bash
npm create one-purple-unicorn my-talk
```

It asks for the talk's title, the presenter and the event, writes `package.json`, `slides.md` (a short starter: cover, intro, sections, two columns, stats, Q&A) and `public/`, and installs. Flags skip the questions: `--title`, `--author`, `--event`; `--no-install` leaves the install to you.
